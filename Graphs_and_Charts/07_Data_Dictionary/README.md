This Data Dictionary defines the specific Data Flows used in the Development of a Web-Based Applicant Information and Employment Assistance Management System for the Public Employment Service Office (PESO) of Agoo, La Union. It specifies the source, destination, description, and exact data attributes for each flow:
‎
‎Key Highlights
‎​Inflow Processes: Captures basic demographic data, contact info, and skill profiles directly from applicants to initialize their records.
‎​Document Bundle: Requires specific official credentials for validation (such as PSA birth certificate, Diploma, Transcript of Records [TOR], and Government Valid IDs).
‎​Administrative Routing: Automatically routes applications and uploaded records to the PESO Admin to enable status validation, document checks, and status reporting back to the applicant.
