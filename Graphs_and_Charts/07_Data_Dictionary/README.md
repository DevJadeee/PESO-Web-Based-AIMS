## Data Dictionary

This Data Dictionary defines the specific **Data Flows** used in the development of a **Web-Based Applicant Information and Employment Assistance Management System for the Public Employment Service Office (PESO) of Agoo, La Union**.

It specifies the **source, destination, description, and exact data attributes** for each data flow.

### Key Highlights

**1. Inflow Processes**

Captures basic demographic data, contact information, and skill profiles directly from applicants to initialize their records.

**2. Document Bundle**

Requires specific official credentials for validation, such as:

- PSA Birth Certificate
- Diploma
- Transcript of Records (TOR)
- Government-issued Valid IDs

**3. Administrative Routing**

Automatically routes applications and uploaded records to the **PESO Admin** to enable:

- Application status validation
- Document verification and checking
- Application processing
- Status reporting back to the applicant
