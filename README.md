# PESO-Web-Based-AIMS
Development of a Web-Based Applicant Information and Employment Assistance Management System for PESO of Agoo, La Union

## Project Description

This project aims to develop a web-based applicant information and employment assistance management system for the Public Employment Service Office (PESO) of Agoo, La Union. The system centralizes applicant records, manages employment programs, tracks application status, verifies submitted documents, and generates reports to improve the efficiency of PESO services.
